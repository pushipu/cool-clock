# Установка Cool Clock в Windows

Один установщик подходит для Windows 10/11 на Intel/AMD x64 и ARM64.
Это предварительная версия; автоматический запуск на реальном ПК ещё требует
проверки. Установщик пока без цифровой подписи.

1. Скачайте `Cool-Clock-0.9.1-Windows-Setup.exe` из выпуска для Windows и запустите.
2. Выберите, нужен ли звук и минутные сигналы. При первой установке звук выключен.
3. Дождитесь копирования файлов. Если потребуется WebView2 Runtime, мастер
   установит его через официальный загрузчик Microsoft; понадобится интернет.
4. Пройдите четыре шага настройки ниже. Кнопки открывают системные окна,
   выделенные строки подсказывают нужные значения. «Далее» не применяет
   настройки Windows и не подтверждает, что вы их проверили.

## 1. Выберите Cool Clock

Нажмите **«Выбрать Cool Clock в Windows»**. Эта кнопка заменяет текущую выбранную
заставку на установленный Cool Clock и открывает системное окно. Проверьте поле
**«Заставка / Screen saver»**. Через **«Параметры… / Settings…»** можно изменить звук.

Путь вручную в Windows 10/11: **Пуск → Параметры → Персонализация →
Экран блокировки → Заставка**. Название ссылки зависит от языка Windows.
Если параметры недоступны и ими управляет организация, обратитесь к администратору.

## 2. Сохраните интервал

В окне заставки задайте **«Интервал / Wait»**, например **2 минуты**.
Нажмите **«Применить / Apply»**, затем **OK**. Флажок запроса входа после
заставки оставьте в выбранном вами состоянии. Мастер не меняет этот параметр.

## 3. Проверьте отключение экрана и сон

Нажмите **«Открыть параметры питания»**. В Windows 11 это раздел системы
«Питание и батарея» либо «Питание»; в Windows 10 — «Питание и спящий режим».
Найдите таймеры отключения экрана и перехода в спящий режим. Оба должны быть
больше интервала заставки: например, заставка через 2 минуты, экран и сон через
10 минут. Это пример, значения выбираете вы. На ноутбуке проверьте отдельно
питание от сети и батареи.

## 4. Проверьте просмотр и автоматический запуск

Откройте параметры заставки кнопкой мастера и нажмите **«Просмотр / Preview»**.
Убедитесь, что часы и облака движутся. Движение мыши завершит просмотр.
Нажмите **«Применить / Apply» → OK** и не трогайте мышь и клавиатуру в течение
выбранного интервала. Должна запуститься именно заставка.

Работа «Просмотра» ещё не подтверждает автозапуск. Если экран погас или часы
не появились, проверьте выбор Cool Clock, сохранённый интервал и таймеры экрана
и сна. Win+L не заменяет проверку запуска по бездействию.

Порядок настройки и ссылки на системные разделы сверены с документацией
Microsoft: [настройка заставки](https://support.microsoft.com/en-us/windows/configure-a-screen-saver-in-windows-a9dc2a0c-dc8e-9161-d270-aaccc252082a),
[открытие параметров Windows](https://learn.microsoft.com/en-us/windows/apps/develop/launch/launch-settings),
[управление питанием](https://support.microsoft.com/en-us/windows/experience/power-battery/power-settings-in-windows-11).

Файлы находятся в `%LOCALAPPDATA%\Cool Clock`. Удаление доступно в списке
установленных приложений Windows; общий WebView2 Runtime и ваши дополнительные
файлы в этой папке сохраняются.
