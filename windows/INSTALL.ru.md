# Установка Cool Clock для Windows

[Скачать установщик 0.9.3](https://github.com/pushipu/cool-clock/releases/download/v0.9.3/Cool-Clock-0.9.3-Windows-Setup.exe)

Требуется Windows 10 или 11. Один установщик подходит для Intel/AMD x64 и ARM64.
Это предварительный выпуск; установщик пока без цифровой подписи.

Установщик и приложение используют русский язык, если он выбран языком интерфейса системы. Во всех остальных случаях включается английский.

## Установка

1. Запустите скачанный установщик и выберите, нужен ли звук и минутные сигналы.
   При первой установке звук выключен.
2. Дождитесь установки. Если потребуется Microsoft WebView2 Runtime, мастер
   загрузит его с сайта Microsoft; для этого понадобится интернет.
3. Пройдите четыре шага настройки. Кнопки мастера открывают системные окна,
   выделенные строки подсказывают нужные значения. «Далее» не сохраняет настройки
   Windows и не проверяет ваши действия автоматически.

## 1. Выберите Cool Clock

Нажмите **«Выбрать Cool Clock в Windows»**. Эта кнопка заменит текущую выбранную
заставку на Cool Clock и откроет её настройки. Проверьте поле
**«Заставка / Screen saver»**. Через **«Параметры… / Settings…»** можно изменить звук.

Другие кнопки мастера только открывают настройки. Путь вручную:
**Пуск → Параметры → Персонализация → Экран блокировки → Заставка**.
Если выбор заблокирован организацией, обратитесь к администратору.

## 2. Сохраните интервал

Задайте **«Интервал / Wait»**, например **2 минуты**.
Нажмите **«Применить / Apply» → OK**. Флажок запроса входа после заставки
оставьте в нужном вам состоянии: мастер его не меняет.

## 3. Проверьте экран и сон

Нажмите **«Открыть параметры питания»**. В Windows 11 это раздел «Система →
Питание и батарея» либо «Питание»; в Windows 10 — «Система → Питание и спящий режим».

Таймеры отключения экрана и перехода в сон должны срабатывать позже заставки.
Например: заставка через 2 минуты, экран и сон через 10. На ноутбуке проверьте
отдельно питание от батареи и от сети.

## 4. Проверьте запуск

Откройте параметры заставки и нажмите **«Просмотр / Preview»**. Убедитесь,
что часы и облака движутся. Движение мыши завершит просмотр.
Нажмите **«Применить / Apply» → OK** и не трогайте мышь и клавиатуру в течение
выбранного интервала, чтобы проверить автоматический запуск.

Если экран погас раньше или часы не появились, проверьте выбор Cool Clock,
сохранённый интервал и таймеры экрана и сна. Работа «Просмотра» сама по себе
не подтверждает автозапуск; Win+L тоже не заменяет эту проверку.

## Обновление и удаление

Для обновления запустите новый установщик. Удаление доступно в списке
установленных приложений Windows. Файлы Cool Clock находятся в
`%LOCALAPPDATA%\Cool Clock`; дополнительные файлы пользователя в этой папке
и общий Microsoft WebView2 Runtime при удалении сохраняются.

Автозапуск и работа после блокировки на реальном ПК пока не подтверждены.
[Справка Microsoft о настройке заставки](https://support.microsoft.com/en-us/windows/configure-a-screen-saver-in-windows-a9dc2a0c-dc8e-9161-d270-aaccc252082a).
