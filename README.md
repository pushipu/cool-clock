Те самые суперстильные часы, знакомые каждому. Теперь в виде заставки для macOS и Windows.

## Установка и звук

Язык интерфейса выбирается по системе: русский для русской локали, английский для остальных.

Запустите установщик и выберите, нужен ли звук. Затем мастер покажет, где включить Cool Clock системной заставкой и задать время запуска.

На Mac рядом с системными настройками появляется подсказка. Она также помогает отключить крупные часы macOS, которые могут перекрывать циферблат. В Windows инструкция встроена в страницы установщика; кнопки открывают параметры заставки и питания.

По умолчанию звук выключен. Его можно включить при установке или позже в параметрах заставки. Музыка и последние сигналы минуты синхронизированы с секундной стрелкой. Фон подстраивается под размер экрана без чёрных полос.
