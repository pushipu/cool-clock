# Cool Clock

Заставка для macOS с настоящими облаками, плавающими прямоугольниками и
векторным циферблатом. Восстановлена по старой авторской видеозаписи.

![Cool Clock](docs/preview.png)

## Скачать и установить

[Последний выпуск](https://github.com/pushipu/cool-clock/releases) ·
[Инструкция по установке](docs/INSTALL.md)

В DMG находятся заставка **Cool Clock.saver** и приложение **Cool Clock Preview**.
Откройте заставку двойным нажатием и установите её через macOS. Приложение
предпросмотра можно перенести в «Программы» и запускать отдельно.
Также доступен ZIP только с заставкой. Контрольные суммы — в `SHA256SUMS` релиза.

**Первый выпуск предварительный.** Сборка имеет локальную ad-hoc подпись,
без Developer ID и нотарификации Apple. macOS может потребовать разрешить
открытие в «Системные настройки → Конфиденциальность и безопасность».
Подробнее — в инструкции; отключать защиту macOS не требуется.

## Что внутри

- Два настоящих видео облаков. Metal в реальном времени рисует прямоугольники,
  плавные изменения их размера и переход видео из окон на общий фон.
- Смена фона примерно раз в 8,3 секунды. Фон заполняет любой размер окна
  без чёрных полос; циферблат сохраняет пропорции.
- Текущее местное время, бегущие счётчики и локальные вспышки со свечением
  на минутных отсечках.
- Минутная аудиодорожка. Последние сигналы синхронизированы с секундной
  стрелкой; на длинном сигнале она удерживается на двенадцати.
- В приложении предпросмотра щелчок по часам включает и выключает звук.
  В системной заставке действие мышью завершает показ по правилам macOS.

Минимальная система: **macOS 12**. Бинарники универсальные: Apple Silicon
(`arm64`) и Intel (`x86_64`). Проверка на реальном Mac выполнена на Apple Silicon;
Intel и системный ScreenSaver-host отдельно от нашего предпросмотра пока
не проверены. iPhone-приложения в этом проекте пока нет.

## Сборка из исходников

Нужны macOS с Xcode Command Line Tools и Python 3. Для тестов модели нужен Node.js.
Сторонних Swift-пакетов нет.

```sh
git clone https://github.com/pushipu/cool-clock.git
cd cool-clock
python3 scripts/fetch-media.py
./build-macos.sh
```

Видео и аудио хранятся в GitHub Releases. Загрузчик берёт проверенный ZIP
заставки и извлекает только три нужных медиафайла, проверяя SHA-256 архива
и каждого файла. Уже проверенные файлы повторно не скачиваются.
Для сборки без сети можно передать заранее скачанный ZIP:

```sh
python3 scripts/fetch-media.py --archive /path/to/Cool-Clock-0.7.1-saver.zip
```

Результат сборки: `build/Cool Clock.saver` и `build/Cool Clock Preview.app`.

```sh
npm test
python3 -m unittest discover -s tests -p 'test_*.py'
"build/Cool Clock Preview.app/Contents/MacOS/CoolClockPreview" --self-test
./scripts/package-macos.sh
```

Упаковщик создаёт DMG, ZIP заставки и `SHA256SUMS` в `dist/`.

## Проверка и производительность

Фон использует три аппаратных видеопотока из двух файлов со смещениями
0/7/13 секунд. Кадры повторно используются во всех окнах. Геометрия и видео
привязаны к обновлению экрана через CVDisplayLink; фон выводится до 60 кадров/с,
циферблат — до 30. При остановке заставки воспроизведение прекращается.
Предпросмотр также приостанавливается, когда его окно свёрнуто или полностью скрыто.

На M1 Max в 40-секундном замере версии 0.7.0, окно 984×718 при масштабе 2×:
2399 кадров, среднее время GPU-композиции 0,66 мс; CPU процесса — 26,2% одного
ядра. У каждого видеопотока было 2–4 единичных удержания кадра за замер.
В версии 0.7.1 свечение добавило около 0,43 мс к отдельной отрисовке кадра
циферблата. Это разные замеры; они не измеряют расход батареи.

Команды для повторной проверки:

```sh
"build/Cool Clock Preview.app/Contents/MacOS/CoolClockPreview" --benchmark /tmp/cool-clock-benchmark.json --seconds 40
"build/Cool Clock Preview.app/Contents/MacOS/CoolClockPreview" --render-preview /tmp/cool-clock.png --time 3.1
```

Самопроверка загружает настоящий `.saver`, проверяет видео, звук, остановку
и возобновление, изменение размера и переходы через конец всех трёх видеопотоков.
Длительная работа в системном режиме и энергопотребление пока не проверены.

## Исходники и материалы

- `macos/` — заставка, предпросмотр, отрисовка и аудио.
- `clock-glyphs.js` — контуры цифр, которые сборщик переносит в нативный пакет.
- `clock-model.js` и тесты — расчёт времени, сигналов и бликов.
- `assets/rectangle-tracks.json` — геометрия прямоугольников.
- `assets/release-media.json` — адрес и контрольные суммы медиа.
- [Источники облаков и условия использования](assets/CREDITS.md).

Исходная авторская запись, промежуточные рендеры и старый браузерный
прототип в публичный репозиторий не входят. Облака сняты камерой;
это новые футажи взамен утраченных оригиналов. Геометрия и анимация
восстановлены по записи и не претендуют на побитовое совпадение с ней.
