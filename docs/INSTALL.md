# Установка Cool Clock для macOS

Требуется macOS 12 или новее. Пакет содержит код для Apple Silicon и Intel.
Этот предварительный выпуск подписан локально (ad-hoc), без сертификата
Developer ID и нотарификации Apple. На другом Mac система может заблокировать
первое открытие.

## Заставка

1. Откройте образ `Cool-Clock-<версия>-macOS.dmg`.
2. Дважды нажмите `Cool Clock.saver` и подтвердите установку средствами macOS.
   Если система предлагает выбор, установите только для текущего пользователя.
3. В системных настройках откройте раздел «Заставка» и выберите Cool Clock.
   В macOS Monterey этот раздел находится в «Рабочий стол и заставка».

В образе `Cool Clock.saver` является ссылкой на пакет внутри приложения
предпросмотра. После установки заставка хранится на Mac самостоятельно:
образ можно извлечь, приложение предпросмотра оставлять необязательно.
Альтернатива DMG: распакуйте `Cool-Clock-<версия>-saver.zip` и откройте
находящийся внутри `Cool Clock.saver`.

## Приложение предпросмотра

Перетащите `Cool Clock Preview.app` на значок Applications в образе и откройте
приложение из папки «Программы». Можно менять размер окна; нажатие на циферблат
включает или выключает звук. Закрытие окна или ⌘Q завершает приложение.
Звук в приложении включён при запуске.

При системном показе заставки движение мыши или нажатие клавиши завершает показ.
Переключение звука нажатием работает только в приложении предпросмотра.

## Если macOS блокирует открытие

Сначала попробуйте открыть скачанный файл. Если macOS сообщает о неизвестном
разработчике и вы доверяете этому выпуску, откройте «Системные настройки» →
«Конфиденциальность и безопасность» и используйте «Всё равно открыть» для
заблокированного компонента, если эта кнопка доступна. В старых версиях macOS
настройка может называться «Защита и безопасность». На управляемом Mac
администратор может запретить такие исключения.

Официальная инструкция Apple: https://support.apple.com/102445

Не требуется отключать Gatekeeper, менять настройки блокировки экрана или
удалять атрибуты безопасности файлов. Если система не предлагает разрешить
запуск, этот предварительный выпуск на данном Mac не подтверждён.

## Проверка загрузки

Загрузите `SHA256SUMS` из того же релиза и сравните SHA-256 скачанного файла
с соответствующей строкой. Например, для версии 0.7.1 в Терминале, из папки
загрузки:

```sh
shasum -a 256 Cool-Clock-0.7.1-macOS.dmg
```

Если скачаны оба архива, выполните `shasum -a 256 -c SHA256SUMS`.

## Ограничения предварительного выпуска

Проверки выполнены на Apple Silicon в собственном приложении предпросмотра.
Работа на физическом Intel Mac, длительный показ системным ScreenSaver-host
и установка скачанного пакета на чистом Mac отдельно не подтверждены.
Исходный код опубликован без открытой лицензии; сведения о сторонних облачных
видео и их лицензии CC0 находятся в `Credits.txt`.
