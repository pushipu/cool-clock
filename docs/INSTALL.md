# Установка Cool Clock для macOS

Требуется macOS 12 или новее. Пакет содержит код для Apple Silicon и Intel.
Этот предварительный выпуск подписан локально (ad-hoc), без сертификата
Developer ID и нотарификации Apple. На другом Mac система может заблокировать
первое открытие.

## Установка через мастер

1. Скачайте и откройте `Cool-Clock-0.8.0-macOS.dmg`.
2. Запустите единственное приложение в образе, **Cool Clock Installer.app**.
3. Нажмите «Продолжить» и выберите, воспроизводить ли музыку и минутные сигналы.
   При первой установке звук выключен.
4. Нажмите «Установить». Мастер установит оба компонента для текущего пользователя.
5. Нажмите «Открыть настройки macOS», найдите раздел «Заставка» и выберите Cool Clock.
   В macOS Monterey раздел называется «Рабочий стол и заставка».
   В macOS 27: «Обои → Заставка… → Другое → Показать все → Cool Clock».

Заставка устанавливается в `~/Library/Screen Savers/Cool Clock.saver`,
предпросмотр в `~/Applications/Cool Clock Preview.app`.

Выбор заставки остаётся за вами: мастер не меняет его автоматически. После
установки образ можно извлечь. При повторной установке мастер обновляет оба
компонента; выбранный в нём звук применяется к обоим при следующем запуске.

## Настройка звука

**Системная заставка:** выберите Cool Clock в системных настройках, откройте
её «Параметры», измените переключатель звука и нажмите «Сохранить».
«Отмена» закрывает окно без изменений. Название кнопки параметров зависит
от версии macOS. Движение мыши и нажатие клавиши завершают показ заставки.

**Предпросмотр:** откройте `Cool Clock Preview.app` из пользовательской папки
«Программы». Звук переключается щелчком по часам или через меню
«Cool Clock → Настройки…» (⌘,). Выбор сохраняется после закрытия приложения.
Закрытие окна или ⌘Q завершает предпросмотр.

При установке оба компонента получают один выбор звука. После этого их настройки
независимы: изменение в предпросмотре не переключает звук системной заставки.
Для неё используйте штатные «Параметры» в системных настройках.

## Если macOS блокирует открытие

Сначала попробуйте открыть скачанный файл. Если macOS сообщает о неизвестном
разработчике и вы доверяете этому выпуску, откройте «Системные настройки» →
«Конфиденциальность и безопасность» и используйте «Всё равно открыть» для
заблокированного компонента, если эта кнопка доступна. В старых версиях macOS
настройка может называться «Защита и безопасность». На управляемом Mac
администратор может запретить такие исключения.

Официальная инструкция Apple: https://support.apple.com/102445

Не требуется отключать Gatekeeper, менять настройки блокировки экрана или
удалять атрибуты безопасности файлов. Если система не предлагает разрешить
запуск, этот предварительный выпуск на данном Mac не подтверждён.

## Проверка загрузки

Загрузите `SHA256SUMS` из того же релиза и сравните SHA-256 скачанного файла
с соответствующей строкой. Например, для версии 0.8.0 в Терминале, из папки
загрузки:

```sh
shasum -a 256 Cool-Clock-0.8.0-macOS.dmg
```

Если DMG и `SHA256SUMS` находятся в одной папке, выполните
`shasum -a 256 -c SHA256SUMS`. В новых выпусках отдельного ZIP заставки нет.

## Ограничения предварительного выпуска

На Apple Silicon с macOS 27.0.1 проверены мастер установки, обновление,
предпросмотр, системная миниатюра и сохранение звука через «Параметры».
Работа на физическом Intel Mac, длительный показ системным ScreenSaver-host
и установка скачанного пакета на чистом Mac отдельно не подтверждены.
Исходный код опубликован без открытой лицензии; сведения о сторонних облачных
видео и их лицензии CC0 находятся в `Credits.txt`.
